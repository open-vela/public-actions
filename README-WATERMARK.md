# 水印检测功能说明

## 概述

本功能用于自动检测 PR 中提交的图片是否包含敏感水印（如飞书、钉钉等办公软件的个人水印），防止敏感信息泄露。

## 核心原理

基于**几何角度过滤法**进行水印识别：

- **架构图内容**：通常是水平（0°）或垂直（90°）排列，为了排版整齐
- **敏感水印**：飞书/钉钉等办公软件的水印为了防伪，通常会进行 30°~45° 的倾斜处理

**解决方案**：
1. 利用 OCR 提取所有文本框坐标
2. 计算其倾斜角度
3. 凡是倾斜度超过阈值（>10°）的文本，即判定为水印
4. 使用正则表达式匹配 "姓名 + 4位数字" 格式，确认为敏感水印

## 工作流程

### 1. 触发条件
- 当 PR 中包含图片文件（.png, .jpg, .jpeg, .bmp, .gif）时自动触发

### 2. 检测步骤
1. 识别 PR 中新增或修改的图片文件
2. 安装检测依赖（opencv-python, paddleocr 等）
3. 对每个图片执行水印检测
4. 如果发现敏感水印，CI 检查失败并阻断合并

### 3. 检测结果
- ✅ **通过**：图片中未发现倾斜文字或未匹配到敏感信息格式
- ❌ **失败**：检测到 "姓名 + 4位数字" 格式的倾斜水印

## 使用方法

### 本地测试

```bash
# 安装依赖
pip install opencv-python numpy paddlepaddle paddleocr

# 检测单个图片
python .github/workflows/detect_watermark.py path/to/image.jpg

# 检测整个目录
python .github/workflows/detect_watermark.py path/to/images/
```

### CI 集成

水印检测已集成到 `checkpatch.yml` workflow 中，会在以下情况自动运行：
- Pull Request 被创建、更新或重新打开时
- PR 中包含图片文件变更时

## 配置参数

在 `detect_watermark.py` 中可调整以下参数：

```python
# 角度阈值：文字倾斜超过此度数被认为是水印
MIN_ANGLE_THRESHOLD = 10.0  # 默认 10 度
```

## 常见问题

### Q: 识别不到水印？
**A:** 可能原因：
- 图片分辨率太低，尝试提高图片质量
- 水印倾斜角度小于 10 度，可调整 `MIN_ANGLE_THRESHOLD = 5.0`

### Q: 误报架构图文字？
**A:** 
- 流程图的菱形框内文字可能是斜的
- 通过正则表达式约束，只匹配 "人名+数字" 格式
- 可以调整正则表达式规则来减少误报

### Q: CI 检测时间过长？
**A:**
- 水印检测仅对 PR 中变更的图片进行检测
- 如果图片较多，可考虑并行处理或优化 OCR 参数

## 技术栈

- **OpenCV**: 图像预处理
- **PaddleOCR**: 文字识别引擎
- **NumPy**: 数值计算
- **Python 3.8+**: 运行环境

## 优势

相比于颜色分割或线条去除，角度过滤是从物理几何层面进行的区分：
- 架构图必须横平竖直，否则工程师看不懂
- 水印必须倾斜，否则无法覆盖全图且容易被涂抹
- 这个矛盾是不可调和的，因此也是最稳定的识别特征
